# prototipo_currículo

# 💼 Currículo Pessoal — Isadora Moraes Navarro

Este projeto foi desenvolvido durante o curso de **Desenvolvimento de Sistemas do SENAI SP**, utilizando HTML5 para criar uma página pessoal com informações profissionais, habilidades, projetos e formas de contato.

A proposta é colocar em prática conceitos básicos de desenvolvimento Web, trabalhando com textos, imagens, links, tabelas e formulários.

## 🎯 Finalidade do Projeto

O objetivo da página é apresentar um pequeno currículo pessoal em formato de site, reunindo informações sobre minha formação e conhecimentos na área de desenvolvimento.

A página foi organizada para permitir que o visitante encontre facilmente:

* Informações sobre a desenvolvedora;
* Habilidades e conhecimentos;
* Projetos realizados;
* Tecnologias utilizadas nos projetos;
* Formas de entrar em contato.

## 🛠️ Recursos Utilizados

Para desenvolver a página, foram utilizados recursos do **HTML5**, incluindo:

* Estrutura básica de uma página HTML;
* Títulos e parágrafos;
* Links internos e externos;
* Imagem;
* Listas;
* Tabela de projetos;
* Formulário de contato;
* Campos de texto e seleção;
* `<fieldset>` e `<legend>`;
* Links para projetos no GitHub.

## 🔗 Navegação da Página

A página possui um pequeno menu no início, permitindo acessar determinadas partes do conteúdo através de links internos.

As opções disponíveis são:

* Sobre;
* Projetos;
* Contato.

Essa navegação utiliza âncoras HTML para direcionar o visitante às seções correspondentes.

## 📋 Formulário de Contato

A página também possui uma área destinada ao contato com o visitante.

O formulário está organizado dentro de um `<fieldset>` com o título **"Dados do Contato"** e possui os seguintes campos:

* Nome;
* E-mail;
* Assunto;
* Mensagem;
* Botão para enviar.

O campo de assunto possui opções como **Oportunidade de Trabalho, Dúvida, Sugestão e Outro**.

## 🖼️ Imagem

Foi adicionada uma imagem na seção **Sobre Mim**, utilizando a tag `<img>`.

A imagem possui:

* Largura: 200 pixels;
* Altura: 200 pixels;
* Texto alternativo definido pelo atributo `alt`.

## 📞 Informações de Contato

Ao final da página são disponibilizados dados para contato, incluindo:
